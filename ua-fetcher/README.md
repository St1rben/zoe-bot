# Маячок на украинском хостинге

## Зачем это

> **Статус:** основной бесплатный путь — GitHub Actions + Tor
> (`.github/workflows/zoe-fetch.yml`): раннер раз в ~5 минут тянет страницу через
> украинский exit-узел и шлёт HTML в `POST /ingest`, а cron воркера сторожит
> свежесть данных и при необходимости сам будит запуск. Этот маячок —
> альтернатива для платного укр. хостинга с cron; контракт тот же
> (`POST /ingest`), код воркера менять не нужно.

`zoe.com.ua/outage` отдаёт страницу **только украинским сетям** (проверено с 25 узлов
check-host.net: все зарубежные, включая Варшаву, Берлин и Москву, — timeout; два
украинских — `200 OK`). Cloudflare-воркер физически не может её загрузить, поэтому:

1. на бесплатном украинском хостинге лежит крошечный `cron.php` (этот маячок);
2. раз в минуту он забирает HTML `zoe.com.ua/outage` и отправляет его в воркер
   `POST /ingest` (авторизация — токен из `config.php`);
3. воркер делает всё остальное: парсинг, дедупликацию, уведомления, команды бота.

## Что уже готово (проверено)

- Воркер **1.1.0** с `/ingest` задеплоен: без токена — `403`, GET — `405`,
  с токеном HTML принимается.
- Токен уже прописан в `config.php` (файл в `.gitignore`, в git не попадёт).
- Файлы для загрузки: `index.php` (страница-статус), `cron.php` (маячок),
  `config.php` (настройки).

## Шаг 1. Бесплатный домен `.pp.ua`

Домен в зоне `.pp.ua` регистрируется и продлевается **бесплатно навсегда** (например,
через nic.ua). Варианты имени: `zoe-alert.pp.ua`, `zoealerts.pp.ua`, `zoe-zp.pp.ua`
(если занято — любое свободное).

## Шаг 2. Заявка в HyperHost (бесплатный тариф)

Условия HyperHost: бесплатный хостинг дают «для сайтів на важливу тематику,
некомерційним організаціям, благодійним фондам… готові підтримати цікаві проекти».
Ответ — **до 24 часов**. Обязательное условие — разместить на сайте ссылку на
HyperHost (наш `index.php` уже это делает).

**Критично:** просить локейшн **Україна (Киев)** — из Амстердама `zoe.com.ua` недоступен.

Куда подать: `hyperhost.ua` → «Хостинг» → выбрать любой тариф → на странице оформления
вариант «отримати безкоштовно» → форма заявки. Либо письмо на `billing@hyperhost.ua`.

## Шаг 3. После одобрения: загрузка файлов

Загрузить в корень сайта (FTP или файловый менеджер панели):

```
index.php   — страница-статус
cron.php    — маячок
config.php  — настройки (уже с токеном; НЕ пересылать публично)
```

Проверка сразу после загрузки:

- `https://<ваш-домен>/` — открывается страница;
- `https://<ваш-домен>/cron.php` — отвечает `ok size=... worker={"ok":true,...}`.

Это и есть тест: если `cron.php` вернул `ok`, значит сеть хостинга видит
`zoe.com.ua` и цепочка до воркера работает.

## Шаг 4. Расписание (cron)

- **Если у хостинга есть cron в панели** (у HyperHost есть): задание `* * * * *`
  → `/usr/bin/php /home/<аккаунт>/<домен>/cron.php` (точный путь виден в файловом
  менеджере; можно и раз в 1–5 минут — воркер сам дедуплицирует).
- **Если cron нет**: бесплатный https://cron-job.org — задача раз в 1–5 минут
  открывать `https://<ваш-домен>/cron.php`. cron-job.org не нужно видеть
  `zoe.com.ua` — он дёргает только наш скрипт.

## Шаг 5. Финальная проверка

- `GET https://zoe-outage-bot.kir245314.workers.dev/health` — появится
  `lastIngestAt` (маячок жив), а `updatedAt` — после первого нового графика.
- Перевод воркера на боевой режим (убрать `DRY_RUN`, поставить вебхук) — делаю я.
